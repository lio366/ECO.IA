18. ## 🧠 Orquestador (`agents/orchestrator/`)
19. 
20. **Clase:** `OrchestratorAgent`
21. 
22. El agente maestro. Coordina a todos los demás agentes, toma decisiones usando LLM y genera reportes ejecutivos.
23. 
24. ### Responsabilidades
25. - Registrar y monitorear el estado de cada agente
26. - Enrutar tareas al agente correcto
27. - Tomar decisiones de alto nivel con OpenAI/Ollama
28. - Generar reportes ejecutivos cada hora
29. - Manejar alertas de otros agentes
30. 
31. ### Tareas programadas
32. | Tarea | Intervalo | Descripción |
33. |-------|-----------|-------------|
34. | `health_check` | 60s | Ping a todos los agentes |
35. | `executive_report` | 3600s | Reporte ejecutivo con LLM |
36. 
37. ### Configuración (`config.yaml`)
38. ```yaml
39. heartbeat_interval: 30
40. health_check_interval: 60
41. report_interval: 3600
42. llm:
43.   provider: openai
44.   model: gpt-4o-mini
45. ```

86. ## 🔧 DevOps (`agents/devops/`)
87. 
88. Deploy automático, auto-healing y backups.
89. 
90. ### Módulos
91. 
92. **`AutoHealer`** — Monitorea y reinicia servicios Docker caídos
93. ```python
94. healer = AutoHealer(
95.     services=['eco-ia-api', 'eco-ia-worker', 'eco-ia-postgres'],
96.     check_interval=60,
97.     max_restart_attempts=3
98. )
99. await healer.start()
100. ```
101. 
102. **`Deployer`** — Gestiona deploys Docker Compose
103. ```python
104. deployer = Deployer(compose_file='docker/docker-compose.yml')
105. deployer.deploy_service('eco-ia-api')
106. deployer.apply_security_updates()
107. status = deployer.get_service_status()
108. ```
109. 
110. **`BackupManager`** — Backups a storage remoto vía rsync
111. ```python
112. bm = BackupManager(
113.     local_paths=['/opt/eco-ia/data', '/opt/eco-ia/config'],
114.     retention_days=30
115. )
116. result = bm.run_backup(label='daily')
117. ```

123. Optimización de CPU/RAM, escalado y limpieza.

126. 
127. **`ResourceOptimizer`** — Métricas en tiempo real
128. ```python

136. **`AutoScaler`** — Escala réplicas Docker según carga
137. ```python
138. scaler = AutoScaler(
139.     min_replicas=1, max_replicas=10,
140.     scale_up_cpu_threshold=70.0,
141.     scale_down_cpu_threshold=30.0
142. )
143. scaler.evaluate_and_scale('eco-ia-api', cpu_percent=82.0)
144. ```
145. 
146. **`Cleaner`** — Limpieza automática de logs y artefactos Docker

222. ## MessageBus — Comunicación entre agentes
223. 
224. ```python
225. bus = MessageBus()
226. 
227. # Suscribir
228. await bus.subscribe('security', handle_message)
229. 
230. # Publicar a un agente específico
231. await bus.publish(Message(
232.     sender='orchestrator',
233.     target='security',
234.     content={'type': 'audit_request'}
235. ))
236. 
237. # Broadcast a todos
238. await bus.publish(Message('orchestrator', '*', {'type': 'health_ping'}))
239. ```

14. ## 🎯 ¿Qué es ECO-IA?
15. 
16. Sistema multi-agente de IA que trabaja 24/7 para:
17. 
18. 1. 🔧 **Autoabastecerse** — monitoreo, auto-recuperación, backups
19. 2. 💰 **Generar ingresos** — API de IA + hosting cobrado con Stripe
20. 3. 🌿 **Ser sostenible** — optimización de recursos, escalado automático
21.

24. ## 🏗️ Los 6 Agentes
25. 
26. | Agente | Función |
27. |--------|---------|
28. | 🧠 **Orquestador** | Coordina todo, usa LLM para decisiones, reportes ejecutivos |
29. | 💰 **Monetización** | Clientes, facturación Stripe, pricing dinámico |
30. | 🔧 **DevOps** | Deploy automático, auto-healing, backups |
31. | 🌿 **Recursos** | Optimiza CPU/RAM, limpieza, auto-scaling |
32. | 🛡️ **Seguridad** | Firewall UFW, detección de intrusiones, auditorías |
33. | 📊 **Analytics** | Reportes diarios, predicción de anomalías |

37. ## 🚀 Deploy (1 comando)
38. 
39. ```bash
40. # En ubuntu@ecoia — OVHcloud US
41. git clone https://github.com/liorvys1981-sys/ECO-IA.git /opt/eco-ia
42. sudo bash /opt/eco-ia/scripts/install.sh
43. ```
44. 
45. ### Post-instalación:
46. 
47. ```bash
48. nano /opt/eco-ia/.env          # 1. Agregar API keys
49. systemctl start eco-ia         # 2. Arrancar contenedores
50. bash /opt/eco-ia/scripts/health_check.sh  # 3. Verificar
51. ```

90. ## 🐳 Docker
91. 
92. ```bash
93. # Arrancar todo
94. docker compose -f docker/docker-compose.yml up -d
95. 
96. # Estado
97. docker compose -f docker/docker-compose.yml ps
98. 
99. # Logs
100. docker compose -f docker/docker-compose.yml logs -f eco-ia-api
101. 
102. # Parar
103. docker compose -f docker/docker-compose.yml down
104. ```

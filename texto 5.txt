42. ## Componentes
43. 
44. ### FastAPI — REST API
45. 
46. - **Framework:** FastAPI 0.115 + Uvicorn 0.34
47. - **Workers:** 4 procesos Uvicorn
48. - **Auth:** API Keys con `hmac.compare_digest` (anti-timing)
49. - **Rate Limit:** 100 req/min por IP (sliding window)
50. - **CORS:** Configurable vía `CORS_ORIGINS`
51. 
52. ### Agentes IA — Multi-Agent System
53. 
54. - **Comunicación:** `MessageBus` async pub/sub en memoria
55. - **Base:** `AgentBase` ABC con lifecycle hooks
56. - **Scheduler:** `TaskScheduler` asyncio — tareas periódicas
57. - **LLM:** `LLMConnector` — OpenAI o Ollama (self-hosted)
58. 
59. ### Celery — Task Queue
60. 
61. - **Broker:** Redis
62. - **Workers:** `eco-ia-worker` (4 concurrencias)
63. - **Beat:** `eco-ia-beat` (scheduler distribuido)
64. 
65. ### Base de datos
66. 
67. - **PostgreSQL 15:** datos persistentes (clientes, facturas, logs)
68. - **Redis 7:** cache, sesiones, Celery broker
69. 
70. ### Monitoreo
71. 
72. - **Prometheus:** métricas de API, sistema, Docker
73. - **Grafana:** dashboards visuales
74. - **AlertManager:** alertas por email SMTP
75.

78. ## Flujo de una request
79. 
80. ```
81. Cliente
82.   → Nginx (rate limit, proxy)
83.     → FastAPI (auth middleware)
84.       → Route handler
85.         → Agent / Service
86.           → LLM / Stripe / DB
87.         ← Response
88.       ← JSON
89.     ← HTTP
90.   ← Response
91. ```

95. ## Seguridad
96. 
97. | Capa | Mecanismo |
98. |------|-----------|
99. | Red | UFW firewall (puertos 22, 80, 443, 8000, 3000, 9090) |
100. | SSH | Fail2Ban + SSH key only |
101. | API | HMAC API keys, rate limiting 100 req/min |
102. | Webhooks | HMAC-SHA256 signature verification |
103. | Firewall dinámico | Auto-block IPs maliciosas (10 intentos) |
104. | Contenedores | Usuario no-root (`ecouser`) |
105. | Secrets | `.env` excluido de git, permisos 600 |
